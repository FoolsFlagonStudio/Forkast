# Forkast Frontend

The Forkast marketing website: general information about the app and links to download it from the app stores.

> **Status:** planned. Nothing in this folder has been built yet.

## Scope

This is a static site. It does not call the backend or require login. Planned pages:

| Page           | Purpose                                                                     |
| -------------- | --------------------------------------------------------------------------- |
| Home           | What Forkast does, key features, screenshots, App Store / Google Play links |
| Privacy Policy | Required by the App Store and Google Play                                   |
| Support        | Contact information and FAQ; the App Store requires a support URL           |
